# \## Архітектура: що означає кожен блок

# \- \*\*Client (браузер)\*\*: сторінки на HTML/CSS/JS; користувач бачить інтерфейс і надсилає запити до API.

# \- \*\*Backend (REST API)\*\*: сервер на Node.js + Express; приймає запити, перевіряє права, виконує бізнес-логіку, повертає JSON.

# \- \*\*Database\*\*: SQLite; зберігає користувачів, матеріали, коментарі, скарги.

# \- \*\*Auth\*\* (майбутній): реєстрація, вхід, видача токенів, ролі.

# \- \*\*Materials \& Search\*\*: додавання, пошук і фільтрація матеріалів.

# \- \*\*File Storage\*\*: зберігання завантажених файлів із перевіркою типу й розміру.

# \- \*\*Comments\*\*: коментарі до матеріалів.

# \- \*\*Complaints \& Moderation\*\*: скарги, блокування порушників, видалення матеріалів.

# \- \*\*Notifications\*\*: сповіщення про коментарі та результат розгляду скарг.

# \- \*\*Email Service\*\*: відправка листів для скидання пароля.

# \- \*\*AI Assistant\*\*: помічник, що використовує зовнішнє AI API.
